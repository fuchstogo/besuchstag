# Besuchstag Informatik

Workshop-Seite für den Besuchstag der Oberstufe Centrum St.Gallen: micro:bit mit MakeCode in drei Levels (Namensschild, Smiley-Tasten, Schere Stein Papier).

- `index.html`: die Workshop-Seite
- `microbit-leer.hex`: setzt den micro:bit auf ein leeres Programm zurück
- `microbit-hi.hex`: zeigt «Hi» als Lauftext (micro:bit V1 und V2)
