Ihr steckt fest?

  1. Lest den Schritt nochmals zu zweit durch.
  2. Im Tutorial auf die Glühbirne 💡 klicken, dann seht ihr einen Tipp.
  3. Streckt auf, eine Oberstufen-Schülerin oder ein Oberstufen-Schüler kommt zu euch.

Zum Schluss: micro:bit zurücksetzen

Damit die nächste Gruppe frisch starten kann, spielt ihr am Ende eines dieser Programme auf euren micro:bit. So geht’s:

  1. micro:bit mit dem USB-Kabel am Computer anschliessen.
  2. Unten auf eine der beiden Dateien klicken. Sie landet im Ordner Downloads.
  3. Die Datei aus Downloads auf das Laufwerk MICROBIT ziehen.
  4. Warten, bis das gelbe Lämpchen auf der Rückseite nicht mehr blinkt. Fertig!
